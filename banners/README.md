# HV Novitas banners

Website-bannerbestanden (beide 1472 × 444 pixels, verhouding 3,315:1):

- `kom-handballen-bij-novitas.webp` — reservebanner om nieuwe leden te werven.
- `mooie-feestdagen.webp` — kerst-/feestdagenbanner.

De bestanden `*-origineel.png` bewaren de oorspronkelijke gegenereerde afbeeldingen.

Na upload naar de map `banners/` in de website-repository zijn de beoogde paden `/banners/kom-handballen-bij-novitas.webp` en `/banners/mooie-feestdagen.webp`. De banners worden met deze bestanden alleen opgeslagen; ze worden niet automatisch op de homepage geactiveerd.
